#  Sistema de Atendimento de Clínica 

 Sistema desenvolvido para simular o atendimento de pacientes em uma clínica, utilizando uma fila de atendimento organizada por níveis de prioridade.

---

##  Funcionalidades

- Cadastro de pacientes
- Listagem de pacientes cadastrados
- Validação de nome, idade e CPF
- Classificação de pacientes por prioridade
- Organização da fila de atendimento
- Chamada do próximo paciente
- Exibição do tamanho da fila
- Identificação do próximo paciente

---

##  Prioridades

O sistema permite classificar os pacientes em:

1. Idoso
2. Criança
3. Deficiente
4. Gestante
5. Obesos
6. Sem prioridade

---

## Tecnologias e conceitos utilizados

- C++
- Estruturas de dados
- Lista encadeada
- Ponteiros e memória dinâmica
