#  Sistema de Concessionária

O projeto simula o cadastro e gerenciamento de carros de uma concessionária, permitindo realizar operações de cadastro, consulta, edição e remoção de veículos.

---

## Funcionalidades

- Cadastro de novos carros
- Geração automática de ID para cada veículo
- Listagem de todos os carros cadastrados
- Busca de veículos através do ID
- Edição das informações de um carro
- Remoção de veículos
- Confirmação antes da remoção
- Validação dos dados informados
- Menu interativo para navegação pelo sistema

---

## Informações dos veículos

Cada carro cadastrado possui:

- ID
- Nome
- Modelo
- Ano
- Preço
