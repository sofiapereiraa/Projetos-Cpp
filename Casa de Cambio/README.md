# Casa de Câmbio

Projeto desenvolvido para simular um sistema de conversão de moedas. O programa permite converter valores em reais (BRL) para diferentes moedas estrangeiras através de um menu interativo no terminal.

---

## 🚀 Funcionalidades

- ✅ Conversão de Real para Dólar (USD)
- ✅ Conversão de Real para Euro (EUR)
- ✅ Conversão de Real para Libra (GBP)
- ✅ Conversão de Real para Iene (JPY)
- ✅ Confirmação antes da conversão
- ✅ Menu interativo no terminal
