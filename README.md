#  Projetos

##  Casa de Câmbio

Sistema de conversão de moedas desenvolvido em C++, permitindo converter valores em reais (BRL) para diferentes moedas estrangeiras.

###  Funcionalidades

- Conversão de Real para Dólar (USD)
- Conversão de Real para Euro (EUR)
- Conversão de Real para Libra (GBP)
- Conversão de Real para Iene (JPY)
- Validação dos valores informados
- Confirmação antes da conversão
- Menu interativo

## Jogo da Forca

Implementação do clássico jogo da forca em C++, desenvolvido para dois jogadores. Um jogador escolhe a palavra secreta enquanto o outro tenta descobri-la antes que as tentativas acabem.

### Funcionalidades

- Modo para dois jogadores
- Definição de palavra secreta
- Exibição da palavra oculta
- Controle de tentativas
- Mensagem de vitória ou derrota

# Sistema de Atendimento de Clínica

Sistema desenvolvido para gerenciamento do atendimento de pacientes, utilizando fila de prioridade e lista encadeada.

### Funcionalidades

- Cadastro de pacientes
- Validação de nome, idade e CPF
- Classificação por prioridade
- Organização da fila de atendimento
- Chamada do próximo paciente
- Remoção do paciente atendido
